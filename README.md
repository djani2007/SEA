# AutoRent

## Описание
AutoRent е уеб базирана система за отдаване на автомобили под наем, разработена с ASP.NET Core MVC. Приложението позволява на клиентите да разглеждат автомобили, да създават резервации, да следят своите наеми и да управляват профила си. Системата включва и административен панел за управление на автомобили, потребители, резервации и контактни съобщения.

## Основни функционалности
- регистрация и вход на потребители;
- разглеждане на налични автомобили;
- филтриране и търсене на автомобили;
- преглед на детайли за автомобил;
- създаване на резервация за наем;
- преглед и анулиране на наеми;
- контактна форма;
- административен панел за управление на системата.

## Потребителски роли
### Клиент
- регистрира се и влиза в системата;
- разглежда и търси автомобили;
- прави резервации;
- вижда история на наемите;
- редактира профила си.

### Администратор
- управлява автомобилите;
- следи потребителите;
- преглежда и променя статусите на резервациите;
- разглежда контактните съобщения;
- използва административно табло със статистика.

## Технологии
- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- ASP.NET Identity
- Bootstrap

## Структура на проекта
- **AutoRent.Core** – бизнес логика, модели, интерфейси и услуги;
- **AutoRent.Infrastructure** – достъп до данни, база данни, repository класове;
- **AutoRent.Web** – контролери, изгледи, view models и статични ресурси.

## Стартиране на проекта
1. Отвори решението `AutoRent.sln`.
2. Провери connection string в `AutoRent.Web/appsettings.json`.
3. Изпълни миграциите към базата данни.
4. Стартирай проекта чрез Visual Studio или `dotnet run`.
